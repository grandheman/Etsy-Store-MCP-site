# Personal Shop Connector — public information site

This repository contains only a static project information page for a private
connector being developed for the owner's Etsy shops. It does not contain
the connector implementation, credentials, or a public service.

Published URL: https://grandheman.github.io/Etsy-Store-MCP-site/

The connector is not yet production-ready or represented as approved by Etsy.
There are no instructions here asking sellers to generate API credentials.
